# VoxTurbo

Бесплатная локальная голосовая диктовка для Windows. Работает на локальной модели. Активируется по горячей клавише или кнопке. Сохраняет содержимое вашего буфера обмена. Сети для диктовки не требует: сеть нужна только один раз, чтобы скачать модель.

## Как это работает

1. Поставьте курсор в поле ввода (например, в чат мессенджера или поле ввода в харнессе).
2. Нажмите клавишу (по умолчанию **F4**) или плавающую кнопку — начнётся запись.
3. Скажите фразу и нажмите ту же клавишу ещё раз.
4. Текст распознаётся локально и вставляется в исходное поле, после чего ваши данные в буфере обмена возвращаются.

Длина диктовки настраивается ползунком от 5 до 60 секунд; по достижении предела запись сама останавливается и начинается распознавание. Горячая клавиша, микрофон, комбинация вставки и задержка возврата буфера настраиваются там же.

## Установка

Готовый установщик публикуется отдельно в разделе **Releases** вместе с файлом `.sha256`.

1. Запустите `VoxTurbo-Setup-<версия>.exe`. Установка идёт для текущего пользователя, без прав администратора, Python и CUDA не требуются.
2. Примите текст лицензии MIT. Лицензии сторонних компонентов остаются в каталоге установки в `_internal/licenses/`.
3. Запустите VoxTurbo и нажмите «Скачать модель» — около 639 МиБ с Hugging Face, каждый файл проверяется по SHA-256. После этого распознавание работает без сети.

Сборка не подписана сертификатом издателя, поэтому Windows может показать предупреждение. Проверяйте SHA-256 скачанного установщика и не отключайте защиту Windows.

## Сборка из исходников

Требуется Windows 10 x64 и Python 3.13 x64; для установщика — Inno Setup 6.7.1.

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
powershell -ExecutionPolicy Bypass -File scripts/quality.ps1
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Для воспроизведения проверенного окружения установите `requirements-lock.txt`, затем `pip install -e . --no-deps`. `scripts/build.ps1` запускает quality gate, собирает onedir-бандл PyInstaller, компилирует установщик Inno Setup и проверяет собранный exe. Готовый файл — `dist/installer/VoxTurbo-Setup-<версия>.exe`, рядом его SHA-256.

Проверки, требующие настоящего буфера обмена или клавиатуры, запускаются отдельно и только в собственных тестовых окнах:

```powershell
.venv\Scripts\python -m voxturbo --self-test --report build/qa/selftest.json
.venv\Scripts\python -m voxturbo --smoke-gui --data-dir build/gui-data --report build/qa/gui.json
.venv\Scripts\python scripts\windows_smoke.py --run
```

## Приватность

Распознавание идёт локально на CPU через ONNX Runtime. Телеметрии нет. Аудио не сохраняется на диск, текст диктовок и содержимое буфера не попадают в логи и в файлы настроек. В сеть приложение выходит только по нажатию кнопки загрузки модели, по закреплённым HTTPS-адресам и с проверкой SHA-256.

## Ограничения

Целевая система — Windows 10. Неизвестные форматы буфера обмена приводят к безопасному отказу до замены содержимого — текст при этом остаётся в окне приложения. Приложение не обещает точность распознавания на любом микрофоне, шуме и акценте, не проверяет, прочитало ли текст чужое приложение, и не восстанавливает буфер после принудительного завершения процесса.
